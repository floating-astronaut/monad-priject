# Demo and pitch card — retired

This card is retired as of DEMO-1 (2026-07-26). It carried a second copy of the
talk track, and the copies drifted: this one still said "10 MON", "100 MON" and
"Set amount to 5 MON" long after OP-1 Q8 made amounts abstract policy units and
the UI stopped displaying MON at all. A judge reading the drifted version would
have been told the demo moves money, which is exactly what Q8 exists to prevent.
